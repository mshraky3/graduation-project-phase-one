# Graduation Project — Phase 1

**Cross-Device AI Assistant** (working title — the project is not named yet)

An AI assistant that runs locally on the user's strongest device and connects their PC, laptop, phone and tablet directly (peer-to-peer) over the local network, with no internet and no cloud server. It understands files and data across all devices at once.

## Features
1. **Duplicate file detection** — identical or similar files stored on more than one device
2. **Unified search** — search from any device and find a file on another
3. **Password management** — every account and its password across all devices, in one place
4. **Clipboard sync** — copy on one device, paste on another
5. **Screen sharing & remote control** — view and control one device from another
6. **Extra screen** — use a tablet or another device as a second monitor
7. **Direct file sharing** — send files between devices over the local network
8. **Offline records** — see a device's files even when it is switched off (last known state)

## Phase 1 scope
